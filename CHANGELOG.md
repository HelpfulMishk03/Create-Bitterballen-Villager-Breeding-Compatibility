# Changelog

## 1.0.1

Added:
Added villager breeding and pickup compatibility for Sugar-Coated Oliebollen.

Fixed:
Fixed the global compatibility toggle not reliably applying changes when enabled or disabled.

Improved compatibility-state handling so villager food data is only restored when this mod previously changed it.

Prevented disabled-state handling from unnecessarily overwriting villager food compatibility added by other mods.


Compatibility:

-Minecraft: 1.20.1

-Forge: 47.2.0+

-Create: 6.0.6+

-Create: Bitterballen: 1.0.1+

## 1.0.0

Initial release.

I made this so villagers can actually use food from Create: Bitterballen with the normal vanilla food and breeding system.

- Added villager pickup, sharing, and breeding support for supported Create: Bitterballen foods
- Added individual food values for each supported item
- Added individual pickup toggles for each supported item
- Added support for cheese wedges, whole cheese wheels, sandwiches, fries, snacks, seeds, herring, and other finished foods
- Kept vanilla villager behavior instead of replacing it with a custom breeding system
