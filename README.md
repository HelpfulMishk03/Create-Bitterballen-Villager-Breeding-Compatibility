# Create: Bitterballen - Villager Breeding Compatibility

Forge 1.20.1 build of version 1.0.0.

## Required

- Minecraft 1.20.1
- Forge 47.2.0+
- Create 6.0.6+
- Create: Bitterballen 1.0.1+
- Java 17

I made this because I wanted villagers to actually recognize the food from Create: Bitterballen instead of ignoring it.

This keeps the normal vanilla villager system and simply lets supported Bitterballen foods work for picking up, sharing, and breeding. I also made the foods individually configurable so you can change their food value or stop villagers from picking up a specific item.

Made for Minecraft 1.20.1 Forge with Create and Create: Bitterballen.

That's pretty much it. Small compatibility mod, one job.
